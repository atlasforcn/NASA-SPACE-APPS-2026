# 定位與整合驗證報告

觀測與匹配使用同一 DEM，結果僅代表模型內模擬。固定分割沒有用保留集調參；v1 門檻事先凍結，另以獨立三個校準位置的完整、遮擋、噪聲、區外情境擬合殘差／候選差距，得到相同部署值（data/localization-thresholds.json）。覆蓋／起伏門檻仍為工程預設，不是統計校準的信心機率。

保留集 Top-3 命中率：100%（10／10）；目標 ≥90%。命中定義：位置 ≤100 m 且朝向 ≤5°。

## 未解決限制

- 校準集第 3 例搜尋失敗（約 1 km 偏差），被系統拒絕。粗位置／朝向搜尋與局部細化可能漏掉正確盆地。
- 保留集為 10 個固定、較易觀測的位置，搜尋框都包含真值；不能外推到 Jezero 全區。
- 目前信心門檻尚未經大型獨立觀測校準；不把分數稱為定位機率。
- 沒有真實照片擷取、姿態估計、塵霧物理模型及獨立 DEM 誤差。射線在局部 DEM 邊界停止，可能低估遠方山脈。
- 區外觀測、遮擋、噪聲與平坦曲線測試不是對所有錯誤情境的保證。

## 自動檢查

- 匯入前基線：9 項核心測試與 9 項 DEM 測試通過。
- 轉換器測試：合成 Mars GeoTIFF 的座標、數值與缺測流程通過；它不是實際定位精度證據。
- 新增測試：固定種子、真值隔離、候選搜尋、低覆蓋拒絕、平坦曲線歧義、取消、輸入驗證、越界及缺值路線通過。
- 真實資料：官方鏡像重新串流 SHA-256 與本地原始 DEM 一致。資料統計見 artifacts/data-validation.json。
- 瀏覽器：桌面與手機截圖，外部請求 0、頁面錯誤 0；完整觀測定位、遮擋拒絕、估計不變、搜尋取消、搜尋中重設及離線重載通過。
- 實際互動案例：第一候選誤差 25.23 m（不同於固定評估搜尋框），Top-3 共 3 個。

## 全球區域模式（v0.5）

全球數值來源為 MOLA MEGDR 16 ppd，而不是原本的 WMTS 彩色圖。`tests/test_planet.js` 檢查像素中心、經度循環、換日線、南北極、球面方位等距座標往返、區域路線及恢復 Jezero。`tests/test_global_assets.py` 檢查來源與轉換雜湊、位元序及全球顯示經度方向。

`npm run test:pages` 在封鎖外部網路下，建立奧林帕斯山、換日線、北極、南極區域，檢查圖層、規劃、自由路線、行進、實驗定位、地名 popup 建立區域及恢復 Jezero。資料與畫面無 JavaScript 錯誤；結果見 artifacts/global-region-results.json。

這些測試驗證流程與座標處理，沒有證明全球定位精度。Jezero 的 10／10 保留集結果不適用全球 MOLA；全球沒有另行宣稱的定位命中率。由於來源約 3.7 km 一格、原始空格含插值、曲率及姿態模型簡化，全球定位一律不回報可自動套用的 good。極區的經緯度顯示嚴重變形，尚未提供專用極投影地圖。全球高解析光學與地質單元尚未接入。
